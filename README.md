# Barbearia — site de agendamento

Páginas públicas do sistema de agendamento, publicadas pelo GitHub Pages.
Banco de dados, contas e regras ficam no Supabase. A chave em `config.js` é a chave
pública ("anon"/"publishable") do Supabase, feita para ficar no navegador; os dados são
protegidos pelas regras do banco.
